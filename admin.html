How to enable SAML:
  1. Fill in the configuration above
  2. Copy the values
  3. Set them as environment variables in your deployment:
ENABLE_SAML=true
SAML_ENTRY_POINT=https://your-idp.com/saml/sso
SAML_ISSUER=https://your-app.com
SAML_CERT=-----BEGIN CERTIFICATE-----
MIIDXTCCAkWgAwIBAgIJAJC1HiIAZAiUMA0GCSqGSIb3Qa
...
-----END CERTIFICATE-----

Need Help?

To configure SAML for your organization:

  1. Contact your IT/Identity Provider administrator
  2. Provide them with the Service Provider Metadata above
  3. Request the Identity Provider metadata (Entry Point URL and Certificate)
  4. Enter those values above and update your deployment
